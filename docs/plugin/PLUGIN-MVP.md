# MobileGL 插件 APK（配置 UI + 驱动自检 + 驱动管理）— MVP 说明

> 分支：`feat/panvk-android-plugin`  
> 日期：2026-10-31  
> 状态：代码已落库，未在本机编译（本机无 Android SDK/NDK）；需用 GitHub Actions 或装有 Android Studio 的机器构建。

## 1. 定位

本插件是 **Minecraft Java 启动器（Pojav / Zalith / FCL）的渲染器插件 APK**，参考 MobileGlues 2.0（MobileGlues-plugin v2.0.0）的产品形态：

- 对启动器：通过现有 manifest meta-data（`fclPlugin` / `renderer` / `boatEnv` / `pojavEnv`，或 Zalith RendererPlugin-v2 DSL）提供 `libMobileGL.so` 与基础环境变量；
- 对用户：提供配置界面（后端选择、环境变量、驱动包管理）与 **驱动自检**（复用 MobileGL 已有的 Driver POST，不再重写一套）；
- 对后续 PanVK：预留驱动包/ICD 管理，但本阶段不改变渲染路径（MobileGL 仍链接系统 Vulkan loader）。

## 2. 已实现功能

| 能力 | 说明 |
|---|---|
| Compose 配置界面 | Material 3，4 个主页面：首页 / 设置 / 驱动 / 信息；深色主题 |

| 驱动管理 | 导入 zip 驱动包（SAF）、ELF arm64 + 路径穿越 + 体积校验、列表/激活/取消/删除、按模板生成 ICD JSON |
| 驱动自检 | 调用 `PostActivity.runDriverPostJson()`（JNI → `RunGlesDriverPost` / `RunVulkanDriverPost`），解析报告，PASS/WARN/FAIL 表格、逐项展开、分享原始 JSON |

## 4. 配置与文件格式

### 4.1 UI 配置（私有）

`filesDir/plugin/config.json`：

    {
      "schemaVersion": 1,
      "backend": "DirectVulkan",
      "autoSelfTest": false,
      "activeDriverId": null,
      "activeIcdPath": null,
      "env": {
        "MOBILEGL_BACKEND_TYPE": "DirectVulkan",
        "LIBGL_ES": "3",
        "POJAV_RENDERER": "opengles3"
      },
      "theme": "dark"
    }

### 4.2 运行时配置（游戏进程读取）

`/sdcard/MobileGL/runtime.conf`（`key=value`，`#` 注释）：

    # Generated by MobileGL Plugin. Do not edit while Minecraft is running.
    MOBILEGL_BACKEND_TYPE=DirectVulkan
    MOBILEGL_DISABLE_TIMERQUERY=0

读取规则（`ConfigLoader.cpp`）：

1. 若设置 `MOBILEGL_CONFIG_FILE`，读该路径；Android 默认 `/sdcard/MobileGL/runtime.conf`；
2. 仅接受 `LIBGL_*` / `MOBILEGL_*` 前缀；
3. **真实环境变量优先级高于文件**（文件先写入 map，环境变量后覆盖），避免与启动器 `boatEnv/pojavEnv` 冲突。

### 4.3 驱动包格式

zip 根目录必须有 `driver.json`：

    {
      "id": "panvk-g925-abcd1234",
      "name": "Mesa PanVK (Mali-G925)",
      "version": "26.3.0-devel",
      "mesaVersion": "26.3.0-devel",
      "abi": "arm64-v8a",
      "kind": "vulkan-icd",
      "library": "lib/libvulkan_panfrost.so",
      "icd": "panvk_icd.json"
    }

规则：`id` 仅 `[A-Za-z0-9._-]{1,64}`；仅 arm64 ELF（`e_machine=183`）；`library` 必须在包内且校验 ELF；可选 `icd` 模板中 `@LIBRARY@` / `${LIBRARY}` 会被替换为实际绝对路径，生成 `icd.generated.json`。

## 6. 已知限制（必须知道）

1. **本机构建已跑通（debug）**：使用用户机器上的 Android SDK（platform 34/build-tools 34）、NDK 27.3 与 CMake 3.22.1、JDK 21（Android Studio JBR）、Gradle 8.10.2 构建成功；产物见仓库根 `dist/`。CI（GitHub Actions）路径尚未在该仓库上实跑，首次推送后仍需看构建日志。
2. **配置生效依赖文件可读**：游戏进程是启动器进程，读 `/sdcard/MobileGL/runtime.conf` 需要启动器具备存储权限；插件 UI 需要“所有文件访问权限”才能写共享路径。无权限时仅写私有副本（对游戏无效），UI 会明确提示。
3. **驱动注入未生效**：系统 `/system/lib64/libvulkan.so` 是 AOSP 自有 loader，**不读取** `VK_ICD_FILENAMES/VK_DRIVER_FILES`（task-2 源码核实）。要真正切换 ICD 必须给 MobileGL 链接自带 Khronos loader（`MOBILEGL_VULKAN_LIBRARY`），且 Khronos loader 1.4.x 的 CMake 在 Android 上直接 `FATAL_ERROR`，需要 patch。该工作推迟到 PanVK 阶段。
4. **自检进程 ≠ 游戏进程**：自检在本插件进程内加载 libMobileGL；游戏进程的驱动能力以实际运行结果为准。
5. **PanVK 内核限制（task-1）**：上游 PanVK 只走 panthor/panfrost；stock 天玑是 kbase（`/dev/mali0`），需社区 kbase 补丁栈（`zenithblue-oss/panvk-kbase-android`）才可能运行；且 PanVK 未必补齐 `fillModeNonSolid`/`vertexPipelineStoresAndAtomics`，换驱动不等于白得扩展。

## 8. Zalith / FCL 兼容

两种启动器走两套插件协议，本 APK 同时声明：

| 启动器 | 协议 | 本 APK 的实现 |
|---|---|---|
| FCL（Fold Craft Launcher）及兼容实现 | legacy meta-data | `fclPlugin=true` + `renderer` / `boatEnv` / `pojavEnv` 占位符（按 flavor 生成 DirectGLES/DirectVulkan 版本） |
| Zalith Launcher（RendererPlugin-v2） | `fclPlugin_V2` 指向 `@string/config` 的 JSON | `mobileGlRendererConfig()` 在 Gradle 里生成与上游 DSL 相同结构的 JSON（displayName/rendererId/rendererGLPath/rendererEGLPath/dlopenLibPaths/env/minMCVer/maxMCVer），并用 `**|libMobileGL.so` 标记由启动器替换为 nativeLibraryDir |

Zalith 配置项（可在启动器内直接调）：

- `MOBILEGL_BACKEND_TYPE`：DirectGLES / DirectVulkan（selectable）；
- `MOBILEGL_DISABLE_TIMERQUERY`、`MOBILEGL_DISABLE_SUBGROUP`、`MOBILEGL_VULKAN_R11G11B10F_FALLBACK`（toggleable，默认关）；
- 标题字符串通过 `meta-data` 索引到 `strings.xml`。

> 说明：上游 dev 已用 Kotlin DSL 迁移到 RendererPlugin-v2；本分支基于较早的 dev，因此用 Gradle 生成等价 JSON，不引入 JitPack DSL 依赖，CI 更稳。

驱动页新增“外部 .so”区块：

### 11.4 SimpleFPEWrapper 支持

- 本构建已把 **官方 SFPEW CI 产物**里的 `libSimpleFPEWrapper.so` 与官方 `libMobileGL.so` 一起打包；
- 渲染链变为：启动器 → `libSimpleFPEWrapper.so` → `SFPEW_EGL`（默认 `libMobileGL.so`）；
- Zalith 配置新增 `SFPEW_EGL`（libEGL.so / libMobileGL.so）与 `SFPEW_RELAXED_CONTEXT`、`SFPEW_NO_MULTIDRAWARRAYS`、`SFPEW_NO_LIST_BATCH` 开关；
- legacy manifest 的 `renderer/boatEnv/pojavEnv` 同步切换为 SFPEW。

### 11.5 官方 .so 直用（不再为本 APK 编译 MobileGL）

构建时传预编译库目录，Gradle 不再依赖 `:MobileGL`：

    # Gradle 属性请用环境变量传，PowerShell 直接 -P 会被拆坏
    $env:ORG_GRADLE_PROJECT_mobilegl.prebuiltLibsDir = "C:/Gradle/sfpew-libs"
    $env:ORG_GRADLE_PROJECT_mobilegl.sfpew = "true"
    gradle -p android-plugin :app:assembleMagmaPluginDebug

本机产物：`dist/MobileGL-SFPEW-MagmaPlugin-debug.apk`（debug 签名，含 SFPEW + 官方 MobileGL）。

> 注意：官方 CI 的 libMobileGL.so 只读环境变量，不读 `/sdcard/MobileGL/runtime.conf`；因此“启动配置”页对官方库不生效。
> 真正生效的配置入口是 Zalith/FCL 的插件设置（`fclPlugin_V2` 的 selectable/toggleable），或换用本项目补丁库后再用 runtime.conf。
